1. Create or open the GitHub profile repository named exactly:

```text

```

2. Upload everything from this package to the repository root.
3. Commit the changes.
4. Open the profile page.
5. Wait for the GitHub Action to generate the contribution snake.

## ⚙️ CONFIGURATION
